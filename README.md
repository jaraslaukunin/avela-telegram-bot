## О проекте

Avela помогает пользователю пройти сценарий предварительной записи на приём к врачу прямо в Telegram.

Бот может использоваться для последовательного выбора параметров записи: медицинского направления, специалиста, даты, времени и других данных, предусмотренных логикой проекта. После подтверждения пользователь получает информацию о своей предварительной записи.

Основная цель Avela — сделать процесс первичного обращения и предварительного выбора времени приёма более понятным, быстрым и удобным.

> Avela не оказывает медицинские услуги, не ставит диагнозы и не предоставляет медицинские рекомендации.

## Возможности

Функциональность развивается и может меняться. В текущих и будущих версиях бот может включать следующие возможности:

| Раздел | Возможность |
|---|---|
| Предварительная запись | Создание заявки на приём к врачу через Telegram |
| Выбор специалиста | Выбор врача или медицинского направления |
| Выбор даты | Просмотр и выбор доступной даты для записи |
| Выбор времени | Выбор свободного временного слота |
| Подтверждение | Проверка данных перед созданием предварительной записи |
| Информация о записи | Отображение выбранных параметров записи |
| Отмена записи | Возможность отмены или изменения заявки при поддержке в версии бота |
| Уведомления | Информирование пользователя о результате действия |
| Обработка ошибок | Понятные сообщения при некорректном вводе или недоступности сервиса |

> Наличие конкретной функции зависит от текущего состояния разработки и версии бота.

## Запуск локально

### Требования

Для запуска текущей версии проекта может потребоваться:

- Python 3.10 или новее;
- `pip`;
- токен Telegram-бота, полученный через [@BotFather](https://t.me/BotFather);
- файл переменных окружения, если он предусмотрен реализацией.

### Клонирование репозитория

```bash
git clone [https://github.com/jaraslaukunin/avela-telegram-bot.git](https://github.com/jaraslaukunin/avela-telegram-bot.git)
cd avela-telegram-bot
```

### Создание виртуального окружения

```bash
python -m venv venv
```

### Активация окружения

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

**Windows cmd:**

```bat
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### Установка зависимостей

Если в проект добавлен файл `requirements.txt`, установите зависимости:

```bash
pip install -r requirements.txt
```

### Настройка переменных окружения

Токен бота нельзя добавлять в исходный код, README или публичный репозиторий.

Пример файла `.env`:

```env
BOT_TOKEN=ваш_токен_бота
```

Файл `.env` следует добавить в `.gitignore`.

### Запуск бота

Точная команда зависит от текущей структуры проекта. После добавления основной точки входа используйте команду, указанную в актуальной версии репозитория.

Типовой вариант:

```bash
python main.py
```

## Использование и ограничения

Avela предназначен исключительно для **предварительной записи** на приём к врачу.

- Бот не является медицинским изделием.
- Бот не заменяет врача, медицинскую организацию, регистратуру или экстренную медицинскую помощь.
- Информация, отображаемая ботом, не является медицинской консультацией.
- Пользователь не должен использовать сервис для постановки диагноза, назначения лечения или изменения назначенной терапии.
- При угрожающем жизни или здоровью состоянии необходимо обратиться в службу экстренной медицинской помощи.
- Предварительная заявка через бота может требовать дополнительного подтверждения медицинской организацией.
